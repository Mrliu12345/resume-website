# 在线简历编辑器（单文件版）

一个零依赖、双击即用的本地简历编辑网站。左侧表单实时编辑，右侧 A4 纸实时预览，支持一键导出 PDF。

## 文件清单

```
简历网站/
├── index.html   # 全部代码（HTML + CSS + JS），单文件，无外部依赖
└── README.md    # 本说明
```

## 快速开始

1. 直接双击 `index.html`，用浏览器（Chrome / Edge / Firefox 均可）打开。
2. 在左侧表单里填写自己的信息，右侧 A4 预览会实时同步。
3. 改完后点右上角 **「导出 PDF / 打印」**，在打印对话框里选「另存为 PDF」即可得到一份干净的简历 PDF。

不需要安装 Node、不需要起服务、不需要联网。

## 功能

- **实时预览**：左侧输入，右侧 A4 纸（794 × 1123 px）立即更新。
- **六大模块**：基本信息、个人简介、工作经历、项目经历、教育经历、技能特长。
- **自定义模块**：编辑器底部「＋ 添加模块」，可添加任意自定义栏目（如自我评价、语言能力、证书 / 奖项、兴趣爱好等），支持双击标题编辑、拖动排序、显示 / 隐藏、删除（可撤销），并自动保存、随简历一起打印。
- **条目增删**：工作 / 项目 / 教育经历支持「+ 添加」和单条「删除」。
- **卡片折叠**：点模块标题可收起/展开，长表单不拥挤。
- **5 套主题色**：顶部圆点切换深蓝 / 墨绿 / 酒红 / 靛紫 / 炭黑，简历标题色与下划线同步变化。
- **自动保存**：所有输入写入浏览器 `localStorage`（key: `resume-data-v1`），关页面再开数据还在。
- **重置**：右上角「重置」按钮确认后清空当前内容，恢复示例数据。
- **打印优化**：`@media print` 自动隐藏编辑区与工具栏，只输出简历本身，A4 页边距 12mm / 14mm。
- **响应式**：窗口宽度 ≤ 1000px 时自动上下堆叠，手机上也能编辑。

## 字段说明

| 模块 | 字段 | 备注 |
|---|---|---|
| 基本信息 | 姓名、职位、电话、邮箱、城市、主页/GitHub | 留空的字段不会出现在简历上 |
| 个人简介 | 多行文本 | 一段式描述 |
| 工作经历 | 公司、职位、开始时间、结束时间、工作内容 | 工作内容每行一条，建议以 `•` 开头 |
| 项目经历 | 项目名、担任角色、开始/结束时间、项目描述 | 同上 |
| 教育经历 | 学校、专业、学历、开始/结束时间、补充说明 | 补充说明可写 GPA / 主修课程 |
| 技能特长 | 每行一项 | 预览区渲染为标签胶囊 |
| 自定义模块 | 模块标题 + 多行内容 | 点「＋ 添加模块」创建，内容每行一条会自动换行显示 |

时间格式自由，示例里用的是 `2021.06` / `至今`，写成 `2021-06` 也可以。

## 注意事项

- **数据存在浏览器本地**：换浏览器、清理浏览器数据、用无痕模式打开都会看不到之前的内容。重要简历改完后请尽快导出 PDF 备份。
- **不要直接改预览区**：所有内容都通过左侧表单编辑；预览区只是展示。
- **自定义模块**：标题与内容都可通过双击模块标题在弹出的编辑框里修改；模块内容也可以直接在卡片内文本框编辑，二者实时同步。删除自定义模块会整块移除（可点撤销条找回）。
- **打印纸张**：打印对话框里纸张选 A4、边距选「默认」或「无」，缩放选 100%，避免内容被裁切。
- **中文字体**：走系统字体栈（PingFang SC / 微软雅黑），无需额外加载字体文件。
- **安全**：单文件、无外链、无统计、无后端，你的简历内容不会离开本机。
- **浏览器要求**：支持 `color-mix()` 与 `localStorage` 的现代浏览器（Chrome 111+ / Edge 111+ / Firefox 113+ / Safari 16.2+）。老旧浏览器下主题色阴影可能不显示，但功能不受影响。

## 技术栈

原生 HTML / CSS / JavaScript（ES6+），无框架、无构建、无外部 CDN。
